Как читать цвета
  • Дни (шт) — тепловая карта: красный = меньше продаж, зелёный = больше. В строке товара цвета сравнивают дни этого артикула между собой; в «Итогах» — дни по сумме всех товаров.
  • Возврат в % — жёлтый → оранжевый: чем выше процент возвратов, тем оранжевее (примерно до 3%).
  • Возврат (шт) — розовый фон, чтобы колонку было видно сразу.
  • Приоритетность — красная ячейка = «горячий» приоритет (нужно внимание).
  • Тип / связь — фильтр «Тип»: готовые сборки или комплектующие (это роль товара). «Статус» — другое: для сборки / дефицит / ок (остаток и работа). Тип считается из названия 1С (скобки с кодами, «набор/комплект/в сборе»). У детали сборки — иконка связи 🔗 (наведи — куда входит; клик — она + все сборки). Клик по строке сборки — сборка + её детали. Повторный клик или «Сбросить» снимает.
